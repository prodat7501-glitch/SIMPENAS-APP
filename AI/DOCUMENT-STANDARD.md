DOCUMENT STANDARDS
=============================

Seluruh dokumen resmi:

- SPT
- SPPD
- SPBY
- Daftar Nominatif
- Kuitansi
- Tanda Terima
- Laporan

WAJIB mengikuti template fisik.

Prioritas:

1. Margin
2. Font
3. Line Height
4. Border
5. Alignment
6. Signature Area
7. Page Break
8. Print Accuracy

Jangan menggunakan layout responsif.

Gunakan:

- Fixed Width
- Fixed Height
- HTML Table
- CSS Grid

apabila menghasilkan output yang lebih akurat.

Dokumen cetak lebih mengutamakan kesamaan dengan template fisik daripada fleksibilitas layout.
